# Symfony Flex recipes

Flex recipes for `klehm/content-blocks` and `klehm/content-blocks-kit`,
served as a self-hosted endpoint from this repository's `flex/main` branch
(regenerated by the [Flex endpoint workflow](../.github/workflows/flex-endpoint.yml)
on every change under `recipes/`).

## What the recipes automate

- Bundle registration (`ContentBlocksBundle`, `ContentBlocksKitBundle`)
- Route mounts (`/_content-blocks/*` + the kit's upload endpoint)
- A documented `config/packages/content_blocks.yaml` template for the two
  **required** host services (`AccessCheckerInterface`,
  `ContentAreaUrlResolverInterface`) and the kit's `FileStorageInterface`
- Post-install notes (entity link, schema update, firewall pattern)

The Stimulus controllers and the `sortablejs` importmap entry are **not**
part of the recipe: Symfony Flex itself syncs them into the host's
`assets/controllers.json` / `importmap.php` from the package's
`assets/package.json` (PackageJsonSynchronizer) on install.

## Consumer setup

Add the endpoint **before** requiring the packages:

```bash
composer config extra.symfony.endpoint \
  '["https://raw.githubusercontent.com/klehm/content-blocks-project/flex/main/index.json", "flex://defaults"]'
composer require klehm/content-blocks klehm/content-blocks-kit
```

## Maintaining recipes

- Layout: `<vendor>/<package>/<major.minor>/` — the version directory is the
  **lowest** package version the recipe applies to, and must be
  `{major}.{minor}` (never `x.y.z`).
- Edit the files, push to master: the workflow regenerates `flex/main`.
- Test locally:

```bash
git clone --depth=1 https://github.com/symfony-tools/recipes-checker.git /tmp/recipes-checker
composer install -d /tmp/recipes-checker --no-dev
cd recipes
git ls-tree HEAD */*/* | /tmp/recipes-checker/run generate:flex-endpoint \
  klehm/content-blocks-project master flex/main /tmp/out --contrib
```

These recipe sources are also the staging ground for an eventual
[symfony/recipes-contrib](https://github.com/symfony/recipes-contrib) PR,
which would remove the endpoint-configuration step for consumers.
