# Recipes

Short, task-focused how-tos for the most common customizations. Each one is grounded in a real extension point — no forking required.

| I want to… | Recipe |
|---|---|
| Add a custom field to the **section** settings sidebar | [Add a section field](./add-section-field.md) |
| Add a field to an **existing / kit block** (e.g. a subtitle on `button`) | [Add a field to a block](./add-block-field.md) |
| **Compress images and serve WebP** (responsive `srcset`, via LiipImagine) | [Compress and convert images](./liip-imagine.md) |
| The same, **with Glide** instead of a bundle (signed URLs) | [Compress images with Glide](./glide.md) |
| Wire a **machine-translation engine** (self-hosted LibreTranslate) | [Machine translation](./translation-provider.md) |
| Write a site's **first pages with AI before launch**, through your own Claude Code login (development only) | [Claude Code as an AI provider](./claude-code-ai-provider.md) |

Looking to build a block from scratch instead? See [Building a custom block](../custom-blocks.md). To restyle blocks or extend the shared **Styling** group, see [Styling](../styling.md).
